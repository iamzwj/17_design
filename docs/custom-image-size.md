# 自定义生图尺寸

生成参数的比例下方提供“自定义”，复用对话生图与瀑布流面板。自定义尺寸使用现有任务字段 `aspectRatio: "宽x高"`，上游收到精确像素字符串；任务重载、重新编辑与再次生成保留该值。预设比例仍使用 `宽:高`，不会改变已有映射。

2026-11-03 核对 GRSAI [尺寸接口文档](https://qmy27nhsd9.apifox.cn/452409160e0)：自定义像素明确限于 `gpt-image-2-vip`。其他模型仅有比例、分辨率档位或预设像素支持时，不推定支持任意像素，自定义入口置灰。

- 最长边 3840 px；两边为 16 的倍数。
- 长短边之比最多 3，面积在 655,360–8,294,400 像素之间。
- 最短可行单边为 480 px（由最小面积、3:1 与 16 px 步长推导）。
- 输入一边后，对边范围取比例、边长和总像素约束的交集；超限或非 16 倍数在失焦时对齐校正，保留所编辑边优先。
- 宽 3840 时高 1280–2160；宽 480 时高 1376–1440。
- 自定义期间分辨率档位不生效，置灰；点击预设比例恢复。切换不支持的模型使用原有比例归一化逻辑恢复预设。

前后端共用 `shared/customImageSize.js`。直接接口和持久化任务接口在扣分/上游请求前拒绝不支持或非法的自定义尺寸；不会静默替换为默认比例。输出文件显示实际返回的像素，不通过放大冒充模型原生尺寸。

验证包括约束边界遍历、本地模拟上游的两条接口请求与错误拦截、双主题桌面及 390px 窄屏的输入和禁用状态。未为本次验证提交付费上游生图。
