# 一键成片升级审查与实施记录

基线：5500448，2026-11-03。先审查再改造，范围仅一键成片。

## 现状

入口 src/App.jsx 的 module=film，页面 FilmStudio.jsx。FilmProduction.jsx 是六阶段观察面板。
服务由 server/films.js 安装，filmWorker.js 独立进程执行 LangGraph，filmPool.js 控制10路并发。
数据：data/films/<project>/project.json 原子快照，原始图片、视频、SRT及多个MP4保存在同目录；无独立影片数据库。
模型：Gemini 3.1 Pro；GPT Image2.5 / Nano Banana2.1；MiniMax H3 / Wan3.0。生成统一走 /v1/api/generate 和 /v1/api/result，保存供应商ID后轮询。
认证复用requireAuth；素材链接HMAC、30分钟；界面3秒轮询；FFmpeg实际拼接、音轨与字幕导出可复用。

## 已验证与缺口

已有：后台恢复、保留供应商ID、10路并发、局部视频重做、真实MP4导出、刷新和模块切换恢复。
缺口：单次计划混合编剧/角色/场景/分镜；没有独立专业Agent成果；事件仅80条且无稳定taskId；素材没有锁定/完整版本；运行中拒绝修改；无编辑时间线及轨道混音。
风险：API与Worker直接改同一快照可能覆盖；旧异步返回无版本校验；暂停停止轮询而非取消供应商任务；声音缺失可被静音填充掩盖；旧字幕按镜头估时。

## 分阶段实施

1. 兼容迁移、任务记录、持久化命令队列、输入版本与旧结果隔离。复用原Worker，不另建调度器。
2. 三栏工作台：阶段导航、真实任务事件聊天、成果编辑；顶部总控，底部折叠时间线。
3. 在现有LangGraph添加导演、编剧、角色、场景、分镜任务；代码控制工具和调度，LangChain Runnable负责结构化AI步骤。
4. 角色面部/服饰独立资源、场景昼夜同图、结构化镜头与时间前缀；单镜实际生成限制采用已接入的10秒策略，始终≤15秒。
5. 所有介入写独立命令文件；Worker在安全点应用，旧输出存历史不覆盖新版本；锁定与运行状态分离；下游按引用失效，锁定下游交人工决策。
6. 复用FFmpeg，加入声音抽取、替换轨道、混音、可编辑顺序/裁切/字幕/淡入淡出；原片保留，替换只重合成。

## 验收

每阶段运行对应自动化检查；最终覆盖2角色2场景昼夜故事、10并发、运行中编辑、暂停/恢复、锁定/回退、局部失效、失败有上限、重启/刷新恢复与真实MP4。
模拟模型集成测试与真实供应商端到端验收分别记录，不能互相替代。
